SkinThreads

A tool that aggregates Reddit skincare reviews so you don’t have to scroll for hours. Targets eczema-prone skin users specifically and ranks products by positive mention ratio and not just popularity, to surface hidden gems. It also gives opinionated recommendations based on your concern instead of an overwhelming list.

Core Features

  • Search by concern: filter by flare-up, daily maintenance, or products to avoid. Returns a top recommendation with supporting Reddit comments.
  • Search a product: type a product name, get sentiment breakdown, concern breakdown, and pros/cons from real comments.
  • Compare two products: side-by-side view with an LLM-generated summary of how they differ.

How it works

  • Pulls posts & comments from r/eczema, r/SkincareAddiction, r/AsianBeauty into SQLite via json endpoints.
  • Feeds each comment to an LLM to extract product name, brand, sentiment, concern, and a verbatim snippet
  • Ranks by positive mention ratio with a minimum threshold; a product with 25 mentions at 92% positive beats one with 500 at 65%.
  • Recency weighting and “reformulated” detection to handle discontinued or changed products.

    Tech Stack

  • Python
  • SQLite
  • FastAPI
  • React
  • Anthropic API
